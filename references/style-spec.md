# 风格规范 · 智能配色 · 场景配文

本文件供 `漫画故事` 技能在 Step 3 / Step 5 调用，定义三件可复用的核心知识：
1. 漫画风格的通用规范（从参考图提炼，已去性别/主题固化）
2. 智能配色映射表（按照片氛围推导背景/文字/点缀色）
3. 场景自适应配文表（按主体类型给语气与模板）

---

## 一、漫画风格规范（通用内核）

以下特征对所有照片一致，是"漫画感"的来源，写进 image_gen 的 prompt 时尽量覆盖：

| 维度 | 规范 | 为什么要这样 |
|---|---|---|
| 勾线 | 清晰流畅的黑色外轮廓，粗细均匀，赛璐珞/日系商业插画线稿感 | 漫画区别于写实的第一标志，勾线让画面"插画化" |
| 上色 | 平涂为主 + 局部柔和高光/轻渐变；皮肤浅肤色加淡腮红 | 平涂=卡通感，柔高光=精致不廉价 |
| 明暗 | 弱光影，无强光源；阴影边缘柔和、低透明度 | 杂志头图的明亮干净感，避免写实阴影的脏 |
| 背景 | 纯色或极简渐变 + 少量飘落装饰（风线/落叶/放射速度线/星点） | 突出主体，保持商业简洁 |
| 质感 | 光滑数字插画，无纸张纹理/噪点，杂志封面/公众号头图精致感 | 统一的高级商业调性 |
| 构图 | 主体居中或偏下，可前景遮挡形成层次；视觉动线清晰 | 头图/海报的可读性与聚焦 |

> 不要把参考图的"粉色+女性赋能"当成风格本身。粉色是那张图的配色，女性赋能是那张图的文案——本技能这两项是智能推导的，画风内核才是固定的。

## 二、智能配色映射表

输入：Step 2 的 `dominant_tone` + `mood`。
输出：`bg_color`（浅淡背景，明度高、饱和中低）、`title_color`（同色系深色，保证与背景对比度）、`accent`（点缀色）。

| dominant_tone / mood | bg_color | title_color | accent | 适用场景举例 |
|---|---|---|---|---|
| 暖光 / 日落 / 温馨 | `#FCE4D6` 暖橘粉 | `#B5481E` 深赭 | `#E8A23D` 金 | 人像暖调、美食、夕阳 |
| 冷调 / 蓝 / 夜 / 清冷 | `#D7E3F4` 雾蓝 | `#1F4E79` 深蓝 | `#7FA8D0` 银蓝 | 夜景、冷调人像、雪景 |
| 自然 / 绿 / 户外 / 清新 | `#DCEFD8` 嫩绿 | `#2E6B3E` 深绿 | `#9CCB6A` 黄绿 | 风景、公园、植物、露营 |
| 粉柔 / 甜美 / 少女 | `#FADADD` 粉 | `#C2185B` 玫红 | `#F48FB1` 浅粉 | 宠物、甜美人像、花卉 |
| 美食 / 奶油 / 治愈 | `#FFF3D6` 奶油黄 | `#A65E1E` 焦糖 | `#E0B252` 蜜黄 | 食物特写、咖啡、烘焙 |
| 中性 / 灰 / 建筑 / 城市 | `#E3E7EC` 雾灰蓝 | `#37414B` 炭灰 | `#8A94A6` 灰蓝 | 建筑、街拍、极简风 |
| 紫调 / 梦幻 / 神秘 | `#E7DDF2` 浅紫 | `#5B2E83` 深紫 | `#B07FD0` 浅紫 | 舞台、夜店、梦幻风 |
| 兜底（未知/高对比照片） | `#F2F2F2` 浅灰白 | `#2B2B2B` 近黑 | `#888888` 中灰 | 任何拿不准时，保证可读性 |

**对比度铁律**：`title_color` 必须明显深于 `bg_color`（明度差足够）。脚本渲染时若检测到对比度不足会自动给标题加黑色描边兜底，但优先在配色阶段就选好。

**装饰点缀 / 氛围层（v2.8.1 按场景分级）**：用 `accent` 在四角撒 3–6 个半透明小圆/星形（render_text.py 的 `--decor` 可选）；动效主体靠「放射速度线 + 风线/落叶 + 拟声词爆炸框」（脚本后加，见第九节）。**氛围层（柔光晕/光点/花瓣）按场景分级加（非默认强加，纯增强氛围，用户确认好看）**：清新/活泼/动感场景花瓣+光晕+光点全上；禅意/端庄/静态场景只留柔光点+光晕、不加花瓣（避免破坏宁静）。

## 三、场景自适应配文表

输入：Step 2 的 `subject_type` + `mood`。
输出：文案语气方向 + 主标题/标语/标签的模板与示例（每类给 2–3 套，Step 5 从中组合或据此现编，务必贴合该照片真实内容）。

### 人像 · 单人
- 语气：个性、自我、生活态度
- 标题示例：自在 / 热爱 / 此刻 / 做自己 / 慢生活
- 标语示例："把日子过成自己喜欢的样子" / "认真生活的人，自带光芒" / "今天也要开心呀"
- 标签：可省，或用情绪词如"日常""周末"

### 人像 · 多人 / 合照
- 语气：关系、陪伴、友情/家庭
- 标题示例：我们 / 老友 / 一家 / 同框 / 在一起
- 标语示例："和喜欢的人在一起，就是好时光" / "岁月漫长，幸得有你" / "我们的故事，未完待续"
- 标签：关系词如"闺蜜""家人""团队"

### 宠物
- 语气：可爱、软萌、治愈
- 标题示例：主子 / 今日份治愈 / 拆家小主 / 毛孩子 / 营业中
- 标语示例："被治愈的第 N 天" / "本喵/汪宣布今天由我统治" / "有你在，日子都软了"
- 标签：宠物名/品种，如"豆豆""橘座"

### 风景 / 自然
- 语气：文艺、诗意、远方
- 标题示例：山野 / 远方 / 清风 / 旷野 / 慢时光
- 标语示例："去更远的地方，见更亮的光" / "风很自由，我也想" / "把烦恼留给山风"
- 标签：地点，如"洱海""阳台山"

### 美食
- 语气：食欲、治愈、人间烟火
- 标题示例：烟火 / 好好吃饭 / 食光 / 满足 / 偷得浮生
- 标语示例："人间烟火气，最抚凡人心" / "认真吃饭，是对生活的基本尊重" / "一口下去，烦恼减半"
- 标签：菜品/店名，如"晚餐""老巷面馆"

### 建筑 / 城市
- 语气：节奏、都市、生活感
- 标题示例：城记 / 街角 / 昼夜 / 霓虹 / 归途
- 标语示例："城市的每一盏灯，都有故事" / "在喧嚣里，找自己的节奏" / "走过的街角，都是伏笔"
- 标签：城市/区域，如"上海""三里屯"

### 运动 / 活动
- 语气：活力、热血、坚持
- 标题示例：出发 / 突破 / 热爱 / 此刻 / 不服
- 标语示例："汗水不会骗你" / "坚持的意义，藏在每一次喘息里" / "出发，就赢了一半"
- 标签：项目，如"跑步""滑雪"

### 其他 / 未知
- 用语气中性、通用的"记录/瞬间/美好"方向，标题用"瞬间""美好""记录"，标语用"平凡日子里的光"之类，避免强行贴主题。

> **配文原则**：文案是"为这张照片加一句点睛的话"，不是套万能金句。先想"这张照片最打动人的是什么"，再落字。拿不准就给用户 2–3 套让他选（见 SKILL.md Step 5 确认门）。

## 四、已验证的"照片 → 硬核赛璐珞"生图 Prompt 模板（v4 路线）

经过多轮实测（传原照保身份 + 硬核文字 Prompt 反复校准，女性/男性多组"照片→漫画"配对参考），以下路线最稳，直接复用：

**核心原则**
- **传原照片保身份**（image 参数传原图），不要用"参考漫画图"做风格锚——那样会把参考图里的场景元素（讲台/花束/红线）也复制进来污染画面。
- 用文字精确描述赛璐珞硬指标，并**显式禁止加多余场景元素**（"DO NOT add podium/flowers/red decorations"），强制保留原照片背景。
- 赛璐珞硬指标（男女通用）：粗黑外轮廓线(2-3px) + 细内线(1px)、面部几乎无线靠色块分界、硬边平涂无渐变、二值/三值硬边阴影无中间调、硬边小块高光零柔光。

**中文骨架**
> 把这张照片重绘为硬边赛璐珞平涂动画风格：外轮廓粗黑实线、内部细节细线、锐利干净；面部几乎不画内轮廓线，靠色块分界；纯色硬边上色（皮肤仅加硬边红晕、头发深棕黑平涂+细发丝高光、西装/上衣纯色+窄条形硬边阴影块）；二值硬边阴影无中间调无环境光；眼睛/唇/饰品硬边小块高光无柔光。**绝对无渐变、无柔化过渡、无环境光遮蔽、无厚涂/笔触质感**——纯平涂硬边色块（像动画 TV 截图那种赛璐珞），每个面至多 3 个硬边色阶、色阶之间发丝级硬边。{性别适配}。保持原照片背景（{背景描述}），不要添加讲台/花束/红线等任何额外场景元素。保持人物特征：{subject_desc}。{mood}氛围。正面半身居中。

**English skeleton（模型对英文赛璐珞词更敏感，建议中英混用）**
> Redraw this exact photo in hard-edged cel-shading anime style: thick solid black outer outlines (2-3px), thin inner detail lines (1px), sharp clean vector lines; face has almost NO inner contour lines, color blocks meet directly; flat color blocking with HARD edges (skin near-flat + hard-edged blush, hair deep brown-black flat + thin light strand highlights, blazer/shirt pure flat + narrow bar-shaped hard-edge shadow blocks); 2-3 tonal hard-edge shadow blocks, NO mid-tone gradients, NO ambient occlusion; small hard-edge white highlight blocks on eyes/lips/jewelry, NO soft glow. {GENDER_ADAPT}. KEEP this photo's exact background ({bg}), DO NOT add podium/flowers/red decorations/extra scene elements. KEEP features: {subject_desc}. {mood} mood. Front half-body centered. MANDATORY anti-drift: ABSOLUTELY NO gradients / soft transitions / ambient occlusion / subsurface scattering / painterly brush texture — flat HARD-edge color blocks ONLY (cel shading like an anime TV-screencap), at most 3 flat tonal steps per surface, hairline-hard edges between tones. AVOID painterly, soft gradients, realistic shading, 3D render, semi-realistic digital paint.

### 4.1 ⚠️ 抗漂移升级式重试协议（图3 教训：商务/双男/木门等易漂成半厚涂）
- **判定漂移的硬标准**：终检底图时，凡出现以下任一即判漂移、必须重跑——①阴影有**软渐变过渡**（面部/衣褶见灰度过渡）而非二值硬边；②体积感偏写实、有明暗塑造；③勾线粗而不闭合、色块直接相接无清晰线。
- **第一步（默认）**：用上面 v4 中英模板生图，已内含 `MANDATORY anti-drift` 硬约束。
- **实战教训（2026-10-31 图3·商务双男+木门）**：上一轮"平衡提示词"（参考内容放最前 + 中度否定）在复杂多人/复杂背景（双男商务、木门暖光）仍漂成**半厚涂**（皮肤柔光过渡、缺锐利黑勾线）。本轮生效的修复提示词=**参考内容描述放最前**（保保真、防 v2 过重否定破坏出图）+ 在其后追加**硬性平涂/硬边要求**：`Clean bold black lineart outlines on every form and face. FLAT solid color fills only. HARD-EDGE toon shadows (flat single-tone shadow shapes with sharp boundaries), NO gradients, NO soft shading, NO ambient occlusion, NO subsurface scattering, NO painterly texture.` 该组合一次成功产出纯赛璐珞（勾线清晰、平涂、硬边阴影、非厚涂）。
- **重试/加固模板（若默认 v4 仍漂）**：在参考内容**之后**追加上述硬性平涂/硬边句 + 否定清单——`ABSOLUTELY NO gradients, NO soft transitions, NO ambient occlusion, NO subsurface scattering, NO painterly texture, flat HARD-edge blocks ONLY, cel-shading, anime screencap style, 2-3 flat tones, hard edges between tones`；并把 `cel shading, anime style, flat color, hard edges` 提到句首强制。**关键纪律**：否定清单只能放在"参考内容描述"之后，绝不能放最前（放最前会干扰模型忽略参考图，产出无主体噪点图，见 v2 失败）。
- **再漂（终手）**：明确写 `do NOT make it realistic or 3D; if it looks like digital painting, regenerate`；必要时换更强模型或后处理线稿重描（见 SKILL.md 画风能力边界说明）。
- **绝不发货漂移底图**：漂移底图渲染出来也不是日漫，用户会判「不是日漫」。终检必须用 pixel/几何或 fetch 确认「清晰黑勾线 + 平涂色块 + 硬边阴影」三特征齐全才过关。

## 五、男性照片适配要点（与女性版的差异）

赛璐珞硬指标男女通用，但男性版有以下专属处理，转男性照片时按此微调 Prompt：

| 维度 | 男性适配 | 女性版（对照） |
|---|---|---|
| 线稿 | 主线更粗硬均匀；下颌角/眉弓/鼻梁转折处**保留硬线**强化骨骼 | 全脸趋近色块融合，线条更柔 |
| 肤色 | 底色偏**暖黄**（如 #F5D0B5），阴影偏**红褐**（#C4836B） | 粉白肤色、紫粉阴影 |
| 红晕 | 颧骨**小面积橘红硬边"印章式"**（#E8A080） | 大面积粉柔红晕 |
| 下颌阴影 | 整块**倒三角硬边阴影**强调"方/骨骼感" | 窄浅或省略，保尖下巴 |
| 骨骼阴影 | 颧骨斜向硬块、鼻梁单侧硬条(L型)、眉下明确阴影块 | 颧骨弱/转红晕，鼻梁淡或省 |
| 高光 | **克制**：唇无高光、皮肤哑光 | 唇/鼻尖可有水光点 |
| 头发 | 纯黑硬底+少量深蓝反光，方向线短促如"刺"，顶部留白高光条 | 长发分层流动，光泽长条 |

**用法**：Step 2 分析时识别性别，Step 4 生成时在 Prompt 模板的 `{GENDER_ADAPT}` 处填入对应要点（男性：强调硬朗线稿、暖黄肤色、骨骼硬边阴影、唇哑光无高光；女性：粉白肤色、柔线、粉柔红晕）。

## 六、分层配文范式（复刻漫画版"自动配文"）

漫画版参考图不是简单贴标题，而是**分析照片场景后自动生成分层文字**。技能按此范式配文，再映射到渲染三角色（title / bubble / label）：

| 层 | 作用 | 形式 | 映射渲染角色 | 示例 |
|---|---|---|---|---|
| 状态层 | 即时感、动作/状态 | 状态词 + 语气词(~) | `title` 主标题 | "讲解中~" "今日份治愈" "自在" |
| 价值层 | 升华主题、口号 | 对仗"动名，动名" | `bubble` 对话框 | "分享知识，传递力量~" "把日子过成自己喜欢的样子" |
| 品牌/身份层 | 机构/姓名/地点背书 | 短标识 | `label` 角落标签 | "SPE软实力教育" "形象" "闺蜜" |

**生成逻辑链**：分析图像（人物特征/动作/场景线索/情绪）→ 角色定位（讲师 / 宠物主 / 旅人…）→ 状态层（近景即时）+ 价值层（远景升华）+ 品牌层（从图提取）。
**原则**：对话感（用 ~ 软化语气）、节奏感（状态短 → 价值长）、贴合照片真实内容，不编万能鸡汤。
**确认门**：每图给 1 主 + 2 备三套，让用户选；用户改文直接迭代重渲染（不重生图）。

**男性讲师示例（本组验证）**：照片=中年男性、戴眼镜、浅灰中山装、手持话筒演讲；漫画版自动配文 = 状态层"讲解中~" + 价值层"分享知识，传递力量~" + 品牌层"SPE软实力教育"。同类知识传播者照片可复用此范式。

> ⚠️ 本第六节范式仅适用于「人像特写类」照片（单人/多人特写，聚焦人）。若照片是**带环境的场景照**（图书馆/街道/咖啡馆/教室/运动场等，含多人物与空间纵深），配文逻辑完全不同，见第七节。

## 七、场景/环境类漫画版规范（图书馆组验证）

当照片是**带环境的场景照**时，漫画版采用与人像特写类完全不同的处理。本范式提炼自"图书馆照片→漫画版"配对参考（第一组场景类案例）。

### 7.1 风格差异（场景类 vs 人像特写类）
| 维度 | 人像特写类 | 场景/环境类 |
|---|---|---|
| 背景 | 纯色/极简渐变，突出单人 | **保留并简化真实场景**：书架/街道→色块阵列，保留结构线（立柱/灯带/导视牌） |
| 透视 | 正面平视，主体居中 | **一点透视 + 轻微鱼眼**，强化空间纵深，视角略低增强代入感 |
| 动感 | 一般无 | **大量速度线/放射动态线**（地板、桌腿、衣褶处）强化流动与纵深——日漫空间表现手法 |
| 阴影 | 硬边块阴影 | 灰蓝(#7A8B99)/深灰(#4A5A6B)硬边阴影（非纯黑，保柔和），落于桌下/椅背/褶皱 |
| 高光 | 硬边块高光 | 同，集中于灯管/屏幕/头发反光等金属/玻璃处 |
| 配色 | 智能推导 | 暖木色(#D4B99A书架)+冷灰白(#E0E0E0地)+灰蓝阴影+浅肉肤色(#F5E0D0~#F8C8A0)，主色≤5种克制和谐 |

### 7.2 配文范式（场景类：氛围层 + 环境音层）
场景类漫画版**不写口号式价值层**，而是两层：
- **氛围层**：一句贴合当下情境的轻声感叹（圆润手写体 + 椭圆对话气泡 + ~尾音），落到 `title` 或 `bubble`。例：「今天的阳光 好适合看书呀~」
- **环境音层**：拟声词浮空无框（粗黑体，略倾斜），作画面节奏/生动性点缀（翻书"哗啦"、键盘/脚步"哒哒"）。可映射到 `label` 或 `--decor` 类点缀文字。例：「哗啦」「哒哒」

> 这是与人像特写"状态层+价值层+品牌层"（第六节）**并列的两套范式**。Step 5 先按 `subject_type` 判断照片是"人像特写"还是"场景环境"，再选对应范式，不要混用。

### 7.3 场景/环境类生图 Prompt 变体
在 v4 硬核赛璐珞骨架上**替换构图与背景指令**（不要套用"Front half-body centered"人像版）：
> 把这张照片重绘为硬边赛璐珞平涂动画风格（同 v4 硬指标：粗黑外轮廓+细内线、硬边平涂、二值硬边阴影、硬边块高光零柔光）。**保留并简化完整场景**：书架/街道/家具以纯色块阵列呈现，保留立柱/灯带等结构线；采用一点透视+轻微鱼眼强化空间纵深，地板与桌腿处加放射状速度线增强流动感；灰蓝(#7A8B99)/深灰硬边阴影（非纯黑），白色硬边块高光集中于灯管/屏幕/金属处。{GENDER_ADAPT}。保持原照片背景与多人物布局（{背景描述}），不要添加额外道具。{mood}氛围。

### 7.4 图书馆组实测配文示例
照片=现代图书馆内景，多青年读者学习，明亮冷白光，木质桌椅纵深。漫画版自动配文：
- 氛围层（左上气泡）：「今天的阳光 好适合看书呀~」
- 环境音层（浮空）：「哗啦」「哒哒×3」（分别对应翻书/敲键盘/脚步，作背景音效点缀）
- 配色：暖木+冷灰白+灰蓝阴影，浅肉肤色

"氛围感叹 + 环境音效"可直接复用于其他安静/生活化场景（咖啡馆、自习室、书店、公园）。

## 八、题材风格自适应（风格强度档位）

**重要事实**：通览全部参考图（人像×3、图书馆、花卉、湖水）后发现——**参考图本身在不同题材上风格有漂移**，并非统一一种赛璐珞硬度：
- 人像（商务女性 / 男性讲师 / 男性学习）→ 硬核赛璐珞（粗黑勾线、硬边二值阴影、硬边块高光）
- 场景（图书馆）→ 赛璐珞硬指标 + 灰蓝硬边阴影 + 速度线
- 自然 / 风景（花卉、湖水）→ **更柔的"动漫化氛围平涂"**：清晰但偏细 / 深色的勾线、阴影边缘较柔（非纯硬边）、高光为手绘线条或饱和色块、整体高饱和滤镜感、图案化简化（水面同心圆、树冠色块、生物符号化）

因此技能**不把一种硬度强加所有题材**，提供「风格强度档位」，默认按题材分档，用户可覆盖：

| 档位 | 适用 | 特征 |
|---|---|---|
| 硬核赛璐珞（强） | 人像、宠物（强漫画感 + 保身份） | 粗黑外轮廓 + 细内线、二值硬边阴影、硬边块高光零柔光（v4 路线） |
| 柔润氛围（中） | 自然、风景、水体、植物 | 清晰勾线（可偏细 / 深色非纯黑）、柔边或弱硬边阴影、高饱和、图案化简化、治愈系 |
| 场景写实漫画（中强） | 室内外场景环境（图书馆 / 街道） | 保留环境 + 一点透视 + 速度线 + 灰蓝硬边阴影 |

**风格强度旋钮**：用户可显式要求"硬核赛璐珞"或"柔和一些"，Step 4 按档位选 Prompt 模板。

### 自然类漫画化处理母题（花 / 湖水验证）
- **花卉**：高饱和强化、加昆虫（蜜蜂 / 蝴蝶）作动态主体、白色速度线表"风"、气泡写季节旁白
- **水体 / 风景**：水面同心圆波纹图案化、倒影极简化、树冠 / 石块几何色块化、生物（鸭 / 鸟）符号化并排列成视觉引导线、拟声词表水 / 风声
- **配文**：氛围层（天气 / 季节 / 心情旁白~）+ 环境音层（昆虫 / 水 / 风拟声词）—— 与场景类（第七节）同一套"氛围 + 环境音"范式，再次验证其为**非人像类的通用配文逻辑**（人像类才用第六节的"状态 / 价值 / 品牌"）。

### 自然类配文实测
- 花：氛围层「夏天的味道，是花与风的私语~」+ 环境音「嗡嗡」（蜜蜂）
- 湖水：氛围层「今天的风也很温柔呀～」+ 环境音「哗啦啦」（水声）

## 九、人像头发随机规则（飞扬增强 · v2.2）

**背景**：用户要求人像头发「可以随机——有时候不做变化，有时候重绘成风吹飞扬的效果」。参考图（纯漫画、无真人锚）的飞扬头发 = 发丝掀起分离、S 型流动弧线、蓬松发根隆起、惯性滞后弯、额前透气碎发，整体赛璐珞硬边。

**规则**
1. **默认随机**：人像（单人/多人）生成底图时，随机决定是否对头发做「风扬重绘」（wind-blown dynamic flowing），约 50% 概率；另 50% 保持原照片发型（不强行改）。
2. **用户显式控制**：说「头发飞扬 / 飘扬 / 风扬」→ 强制飞扬；说「保持原发型 / 别改头发」→ 关闭飞扬。
3. **性别约束（重要）**：**男性一律禁用头发飞扬**——男的头发飘会显得不稳重、轻浮；无论 A/B 族，男性人物头发必须服帖静态（不施加发丝飘动/风扬重绘）。此约束优先级高于「默认随机」与「用户未指定」；仅当用户显式对**女性/儿童**说「头发飞扬」才触发。A 族对男性只保留风线/落叶等环境动效，不碰头发。
4. **两条路线（v2.3 修正认知，关键）**：之前误判"真人锚加美化必漂"。反例——某手机原生"照片故事"对同一张真人照做出「粉白透亮+珊瑚腮红+飞扬干净头发+环绕风效+文字基本完整」，画风是**非写实扁平插画（非纯硬边）**；我们工具用**强插画化 prompt** 从原照直出也漫画化（漫画感8/10），不依赖锚定成品。失败不是"美化必漂"，而是"在纯硬边赛璐珞框架里硬塞美化 + 用 `semi-realistic` 半写实措辞"导致偏写实/三角打架。故分两条：
   - **硬边保真路线**（要"干净正品赛璐珞、文字零遮挡"）：图生图贴原照、纯黑硬边、文字逐字零遮挡；不加粉白腮红/飞扬美化，头发静态或极轻风感；此路线下 `ABSOLUTELY NO gradients` 否定清单可用；飞扬句式见第4点硬边款。
   - **照片故事式美化路线**（要"照片故事/美化漫画/粉白+飞扬+照片故事风"）：**非写实扁平插画** + 粉白透亮肤色 + 珊瑚腮红 + 干净飞扬头发 + 两侧浅色弧形风线 + 飘散绿叶；文字允许"参考图级别微遮"（美/修边缘微遮可辨）。**从原照直出即可（强插画化 prompt 已验证），无需锚定成品**；禁用 `semi-realistic`（会让模型保留照片质感、偏写实，像照片不像漫画）。只有"精确复刻某一张特定已有图"才拿那张当锚。类比 PS 滤镜/动作：定义一次、套全部，无需为每张图存样本。
   - 选哪条由用户意图定，勿默认否定美化。
4. **飞扬头发 / 照片故事式美化 Prompt 要点**：
   - **硬边路线（赛璐珞内）**：`long dark hair with wind-blown dynamic flowing motion, S-curve strand flow, swept-back top with cascading lifted ends, separated flyaway tendrils radiating outward, airy forehead wisps, voluminous root lift; flat with thin light strand highlights` + `ABSOLUTELY NO gradients/painterly`。
   - **照片故事式美化路线（推荐·模板化·无需参考图）**：`Transform this real photo into a flat 2D stylized illustration / cartoon, STRONG stylization: simplified clean lineart, flattened color blocks with soft shading, NOT photorealistic, NOT 3D, clearly an illustration; fair porcelain-pink luminous skin with soft coral blush; clean wind-blown flowing hair (strands separated, sweeping up-right, tidy); keep subject identity & outfit; add gentle wind effect: translucent light curved wind-lines flanking the figure (up-left near base, up-right behind head) plus drifting green leaves, low-opacity, never covering text`. 文字保留原照文字（允许边缘微遮）。

### 场景自适应动效映射（v2.8.1 · 据样图修正 + 氛围层按场景分级 · 默认照片故事风格族）
- **默认生图 = 照片故事风格族**，不再默认硬边。硬边保真仅当用户显式要"干净赛璐珞/不美化"时启用。
- **主风格由场景锁死（不随机）**；随机只用于局部微调（落叶数、风线疏密/方向）：
  | Step2 判断 | 命中照片故事族 | 动效元素组合（v2.8 据样图修正） |
  |---|---|---|
  | 通用（所有照片故事图） | 两族通用核心 | **①放射速度线 burst（脚本后加，围绕人物放射·默认开启·不挡脸）②拟声词爆炸框（黑边白底·按场景/动作选词·默认 auto 带概率）** |
  | 静态/优雅/人像特写/室内柔光/有风意境 | **A 族·优雅** | 底图环绕螺旋风线 + 银杏/落叶（按意境强弱）+ 粉白腮红美化；**也带放射速度线 burst** |
  | 动作/户外/运动/生活/动态感 | **B 族·写实生活** | 底图放射/集中速度线意境 + 落叶 + 自然暖肤淡腮红；放射速度线 burst + 拟声词（沙沙/咔嚓/咕嘟…） |
  | 宠物/风景/自然 | 自然类（既有） | 底图白色风线 + 落叶/昆虫 + 拟声词（嗡嗡/哗啦啦）；放射速度线 burst 轻度 |
  | 合照/关系向 | 按主氛围走 A 或 B | 同上，配文走关系向；**double 默认不开放射速度线（避人群脸）** |
- **氛围层（柔光晕/光点/花瓣）按场景分级（v2.8.1 · 用户确认好看）**：放射速度线+拟声词是通用动效核心；**氛围层单独按场景**：清新/活泼/动感（A 族优雅、B 族生活、宠物风景）→ 底图加花瓣+柔光晕+光点；禅意/端庄/静态（禅意静心/阅读静坐/商务正装）→ 底图只加柔光点+柔光晕、**不加花瓣**。
- **禅意/端庄静态场景关速度线用「纯净版」（v2.8.1 · 用户确认）**：此类场景渲染加 `--no_speedlines`，只留氛围层 + 椭圆文字框 + 拟声词（放射速度线会切割面部、与"静"主题冲突，实测纯净版更干净高级）。
- **B 族 Prompt 要点**（模板化·无需参考图）：`Transform this real photo into a photo-story style illustration, realistic-life dynamic variant: flat 2D Asian/Japanese comic illustration, soft cel-shaded with clean lineart (NOT American comic style / no Marvel/DC western comic look / NOT western cartoon / NOT thick paint), slightly idealized but realistic proportions (NOT chibi, NOT photorealistic); natural warm skin with light pink blush; keep subject look & background; add soft radial/converging speed-lines (subtle, low-opacity) + small onomatopoeia burst per action (e.g. 沙沙/咔嚓); clearly an illustration, not a western comic`. 文字保留原照文字。**男性人物须服帖静态发型（不施加风扬），见本节性别约束。**
