# 漫画动效库 v2.0（Effect Library）

> 术语：这些统称**漫画符号 / 效果线（effect lines, manpu）**，是漫画的视觉语汇。
> 本库 = 词汇表（每个元素长什么样、怎么下 prompt、何时禁用）+ 语法（场景→组合）+ 变量（随机项）。
> **核心分工：线条/粒子/光影由绘图模型画进画面（手绘质感）；文字、框、拟声词由程序渲染（绝不出错字）。**

**标注约定**：✅ = 原厂样图已验证；○ = 按漫画惯例推演（待照片验证）。

---

## 〇、如何被任意模型使用（模型无关性）

本库是**纯文本知识 + 纯 Python 脚本**，不绑定任何特定模型，换模型照样生效：

| 你的环境 | 怎么用 |
|---|---|
| 能执行 shell | `python3 scripts/decide_effects.py --scene zen --hair long` → 直接拿到现成 prompt |
| 不能执行脚本 | 按下面「场景→动效决策表」手工选元素，再从「PROMPTS 表」抄对应句子拼成 prompt |
| 任何支持图生图的模型 | prompt 是自然语言，任何 image-to-image 模型都能画（模型越好，手绘感越强） |
| 排版 | 需要 PIL 跑 `comic_story.py`；若目标环境无 Python，按「C 类文字与框规格」用别的工具重画即可 |

**场景判定判据（供任意模型/人判断该用哪类）**：

| 判据 | 指向场景 |
|---|---|
| 闭眼/盘坐/室内极静/无动作 | `zen` |
| 站立正面、无大动作（演讲/讲解） | `still` |
| 大幅度动作、对抗、冲撞、命中 | `action` |
| 位移、腾空、奔跑 | `sport` |
| 户外+落叶+秋色 | `autumn` |
| 花+柔和+女性向 | `spring` |
| 下雨/地面积水/伞 | `rain` |
| 下雪/雪地 | `snow` |
| 夜间+霓虹+车流 | `night` |
| 水面/海滩/湖 | `sea` |
| 车内、机舱、地铁窗 | `car` |
| 食物为主体 | `food` |
| 书架/办公桌/多人自习 | `study` |
| 宠物为主体 | `pet` |
| 西装/影棚/职业肖像 | `business` |
| ≥2 人互动合影 | `group` |
| 表情夸张特写（哭/怒/惊/羞） | `emotion` |

**唯一强依赖**：①能看图判定场景 ②能图生图 ③能渲染文字（这三件任何现代多模态模型都具备）。

## C. 文字与框类（**全部由程序渲染**）

| 编号 | 名称 | 触发场景 | 实现 |
|---|---|---|---|
| C1 ✅ | 拟声词爆框 | 动作/声音/进食/风 | `--sfx "唰/咔嚓/簌簌/沙沙/嘭/咕嘟/噼啪/哗啦"`（锯齿爆框） |
| C2 ✅ | 对话框（椭圆/圆角/胶囊） | 所有场景 | `--t1/--t2` + `--mode single/double`；短句横排椭圆、长句竖排胶囊、带尾巴 |
| C2b ✅ | 同人主副双框 | 同一人两句话 | 上方大椭圆主台词 + 左下小椭圆补充语，各带尾巴 |
| C3 ✅ | 云朵状气泡 | 温柔/梦幻/内心独白 | 需在 `render_text.py` 加 cloud 形状（待实现） |
| C4 ○ | 多拟声词同图 | 环境音丰富（图书馆/街道） | 多个 `sfx` 分散在不同区域，避免重叠 |
| C5 ○ | 贴边大字/出血字 | 强调/封面感 | 拟声词压到画面边缘甚至出血 |

> **对话框不是模型画的**（结论）：原厂边框平滑均匀、文字标准中文字形、尾巴尖角规整 → 模板/程序渲染。模型画中文必错、位置不可控，**必须保持程序渲染**。

## 随机变量（同图多跑几次让用户挑）

| 变量 | 选项 | 依据 |
|---|---|---|
| **发型** | `keep` 保持原照 / `random` 自然发挥（默认）/ `long` 变长飘逸 / `fluffy` 变蓬松 | ✅ 原厂实测：女讲师中长发→及胸飘逸；商务男短发→蓬松放射 |
| **美化强度** | `light` / `medium`（默认）/ `strong` | 须"仍能认出是同一人" |
| **风线数量** | 3~5 道 | 每 prompt 写死一个数 |
| **网点纸** | 开/关 | 日漫感更强，但可能显"脏" |

**纪律**：每次只改一个变量，生成 3-4 版让用户挑。

## 生成流程

```
原照片 → 场景判定（zen/action/autumn/rain…）
      → decide_effects.py 输出「动效组合 + 现成 prompt + 变量」
      → image_gen 一次画进画面（漫画化 + 动效 + 美化 + 发型）
      →（A5/A6/A7 会切脸时）mask_restore.py 禁线区回贴
      → comic_story.py 对话框 + 拟声词 + 排版
成品
```

## 保真风险判据（实测）

| 照片特征 | 保真度 | 处理 |
|---|---|---|
| 主体占画面 ≥35%、清晰、现代照片 | ✅ 高 | 走标准流程 |
| 主体小 / 多人 / 动作复杂 / 老剧照低清 | ⚠️ 低（模型会重新演绎动作） | **提前告知风险** |
